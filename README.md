# Camino Guesser — прототип без Google API-ключа

ВАЖНО: это игровая механика с редактором каталога, не полностью настроенная игра. Проверенных встраиваний панорам внутри нет. locations.js содержит 10 заготовок населённых пунктов на Camino Francés и Camino Portugués Central: Франция, Испания, Португалия. Координаты заготовок приблизительны и нужны только для поиска; в игру они не попадают.

## Публикация
Создайте отдельный репозиторий, загрузите все файлы из архива в его корень. GitHub Pages: Deploy from a branch → main → / (root). Ключи, Google Cloud и биллинг не нужны. Нужен интернет: Leaflet загружается с unpkg.com, карта с tile.openstreetmap.org, панорамы с Google.

## Подготовить первую точку
1. Откройте «Каталог панорам».
2. У нужной заготовки нажмите «Найти панораму». Ссылка указывает только примерный ориентир. Выберите панораму именно на маршруте.
3. В Google Street View: меню панорамы → «Поделиться или встроить изображение» → «Встраивание изображения» → скопировать HTML. Названия пунктов могут отличаться в зависимости от языка интерфейса.
4. На сайте: «Настроить» → вставить код → «Проверить встраивание».
5. Убедитесь, что внутри действительно панорама. Нажмите «Показать координаты на карте» и проверьте точность. Координаты автоматически берутся из готового Google-кода; приложение не генерирует pano ID и не ищет панорамы скрытыми API.
6. Отметьте ручную проверку и сохраните. Одна точка уже позволяет протестировать механику. До 10 проверенных точек участвуют в одной игре без повторов.
7. Когда каталог готов, нажмите «Скачать locations.js для сайта» и замените этим файлом locations.js в репозитории. Иначе ваши точки останутся только в localStorage вашего браузера и девушка их не увидит.
8. Откройте сайт в другом браузере или приватном окне и проверьте публикацию. Браузер, где вы редактировали каталог, продолжит использовать свой локальный каталог.

## Механика
Осмотр и перемещение в Google iframe; отметка на отдельной Leaflet-карте; ответ; расстояние по большой окружности; очки; следующий вопрос; итоговая карта и список результатов. Правильная точка — стартовая позиция встраивания, независимо от последующих переходов внутри Google. Полный балл до 50 м; дальше round(5000*exp(-расстояние_км/100)). Пропуск — 0 очков.

## Ограничения
- Google iframe может раскрывать название места и другие подсказки. Его внутренний интерфейс не контролируется приложением. Атрибуция не закрывается.
- Сайт не может проверить из браузера состояние чужого iframe или текущие координаты после перемещения. Открытие панорамы и точность стартовых координат проверяются человеком.
- Проверяется стандартный формат Google share/embed Street View с pano ID и координатами. Если формат изменится, нужно обновить парсер, а не подставлять вымышленные данные.
- Если встраивание сломалось, перепроверьте и замените код либо снимите галочку готовности. Есть пропуск.
- Это клиентская игра: ответы можно увидеть в исходных данных; защиты от читов нет.
- Игровая сессия хранится в памяти вкладки, каталог — в localStorage. Перезагрузка сбрасывает текущую игру, но не каталог. Экспорт JSON служит резервной копией.
- Стандартные тайлы OSM предназначены для умеренного использования; обязательная атрибуция сохранена, офлайн-предзагрузки нет. Для большой аудитории нужен подходящий провайдер.
- Реальная браузерная проверка панорам и интерфейса в этой среде не выполнена. Скрипты и чистые функции проверены программно.
